# Barlow fonts

Barlow and Barlow Condensed, designed by Jeremy Tribby. Licensed under the SIL Open Font License 1.1 in OFL.txt.

Source: https://github.com/google/fonts/tree/main/ofl/barlow and https://github.com/google/fonts/tree/main/ofl/barlowcondensed. WOFF2 subsets retrieved from the Google Fonts CSS API on 2026-10-09. Latin and Vietnamese subsets are hosted locally; no third-party font requests occur at runtime.
